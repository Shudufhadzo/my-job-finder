# Code of Conduct

## Our standard

Contributors must communicate professionally, welcome constructive technical disagreement, and avoid harassment, discrimination, intimidation, or disclosure of another person's private information.

## Scope

This standard applies in repository issues, pull requests, discussions, reviews, and other project spaces.

## Enforcement

Report unacceptable behaviour privately to the project maintainers. Maintainers may remove content or restrict participation when behaviour threatens a safe and productive project environment.
